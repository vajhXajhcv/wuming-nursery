## 一、项目概述

**docx-formatter-cn** 是一套面向中文学术写作场景的 Markdown 转 Word 排版工具，核心目标是让高校师生、科研人员用纯 Markdown 专注内容，最终一键生成符合学校或期刊格式要求的 Word 文档。

项目以网站 `wumingmp.me` 为产品主页与流量入口，已形成：

- 在线工具 `/tools/md2docx`：浏览器内本地运行，免费体验；
- 产品主页 `/projects/docx-formatter-cn`：功能介绍与下载入口；
- 定价页 `/pricing`：Pro 桌面版与论文排版服务；
- 服务页 `/services/thesis-formatting`：人工论文排版服务；
- 使用文档 `/projects/docx-formatter-docs`：模板与 API 说明。

项目定位为 **“AI + 教育科技 + 创作者工具”** 方向的 OPC（一人公司），符合武汉市人工智能 OPC 创新发展若干措施中“以大模型为基础、AI 编程与智能体为核心工具、实现效率超线性放大”的新型创业实体方向。

## 二、市场痛点

中文学术写作人群长期面临以下问题：

1. **格式反复被打回**：毕业论文、课程论文、投稿论文对字体、行距、页边距、目录、图表编号有严格要求，手工调整耗时且易错。
2. **公式与表格排版难**：LaTeX 公式、三线表在 Word 中难以原生编辑，常见工具要么转图片、要么格式错乱。
3. **工具门槛高**：Pandoc 需要命令行，对文科师生不友好；Typora 导出公式变图片；现有方案缺乏中文学术模板。
4. **协作与版本管理弱**：Word 文档难以进行版本控制，而 Markdown 天然适合 Git 管理和多人协作。

目标用户的核心诉求是：**用 Markdown 写内容，最后一步得到格式正确的 Word**。

## 三、产品与服务

### 3.1 核心产品

| 产品形态 | 链接 | 功能 | 定位 |
|----------|------|------|------|
| 在线 Markdown 转 Word | `wumingmp.me/tools/md2docx` | 浏览器内转换，支持公式、三线表、标题编号、模板选择 | 免费引流与体验 |
| docx-formatter-cn CLI / Pro 桌面版 | 待发布 | 批量转换、自定义学校模板、本地图片解析、离线使用 | 付费核心产品 |
| 论文排版服务 | `wumingmp.me/services/thesis-formatting` | 人工接单，按页/按篇收费 | 现金流服务 |
| 模板市场 | 规划中 | 高校模板、期刊模板、行业模板付费下载 | 长尾收入 |

### 3.2 模板体系

已内置模板覆盖：

- **中文学位论文**：毕业论文、课程论文、数学建模、公文、武汉理工毕业设计；
- **期刊 / 预印本**：arXiv Preprint、Nature、Science、IEEE Transactions（单栏近似）、APA Manuscript。

模板以 JSON 配置化，新增模板无需改动代码，可快速扩展。

### 3.3 AI 属性

- **结构化解析**：将非结构化的 Markdown 文本解析为带元数据的文档块（标题、段落、列表、表格、公式、引用等）。
- **智能模板匹配**：根据用户选择的模板，自动应用字体、段落、编号、页眉页脚等排版规则。
- **未来规划**：接入大模型实现“大纲 → 初稿 → 排版”全流程智能体；基于用户历史文档做格式推荐与自动纠错。

## 四、技术方案

### 4.1 技术栈

- **前端**：Astro 静态站点 + 原生 JS，在线工具使用 Pyodide 在浏览器内运行 Python；
- **核心库**：纯 Python 实现，依赖 `python-docx`、`latex2mathml` 及自研 `docx_formatter_cn`；
- **公式引擎**：LaTeX → MathML → Word OMML 原生公式，非截图、可二次编辑；
- **模板引擎**：JSON 配置驱动，支持中文学术、期刊预印本等多样式；
- **部署**：Cloudflare Pages + GitHub 工作流，实现推送即部署。

### 4.2 数据安全

在线版基于 Pyodide 本地运行，文档内容不上传服务器，适合对隐私敏感的学术写作场景。

## 五、商业模式

采用 **免费增值（Freemium）+ 服务变现** 双轮驱动：

1. **免费在线版**：降低体验门槛，获取搜索流量与口碑传播；
2. **Pro 桌面版**：一次性付费或订阅制，面向有批量转换、自定义模板、本地图片需求的用户；
3. **论文排版服务**：面向时间紧、格式要求高的毕业季用户；
4. **模板市场**：高校/机构定制模板付费下载；
5. **企业/机构授权**：面向培训机构、论文辅导机构、出版社批量授权。

## 六、目标用户与市场空间

### 6.1 目标用户

- **高校本科生、研究生**：毕业论文、课程论文、开题报告；
- **科研人员**：投稿期刊、项目申报书、结题报告；
- **教师**：课件、教案、试卷排版；
- **独立创作者**：需要输出规范 Word 的长文作者。

### 6.2 市场空间（估算）

- 全国在校研究生约 350 万，本科生约 4700 万，每年毕业生超 1000 万；
- 学术写作工具属于高频、强痛点场景，用户付费意愿集中在毕业季；
- 竞品多为国外工具或命令行工具，中文本土化和模板深度是核心差异化。

保守估计，首年目标用户 1–3 万人，付费转化率 1–3%，即可实现数万元到十万元级别的年收入。

## 七、竞争优势

| 竞品 | 痛点 | 我们的优势 |
|------|------|------------|
| Pandoc | 公式转图片、中文模板弱 | 公式可编辑、中文模板深度定制 |
| Typora 导出 | 公式变图片、无学术模板 | 原生 OMML 公式、多模板支持 |
| Word 手工排版 | 耗时易错 | 一键生成、可复用模板 |
| 海外排版工具 | 贵、中文支持差 | 本土化、价格亲民 |

核心壁垒：

- **中文排版知识沉淀**：中文学术格式规则复杂且分散，难以快速复制；
- **模板可配置化**：新增学校/期刊模板成本低；
- **产品即内容**：网站博客、笔记持续输出，形成自然流量。
