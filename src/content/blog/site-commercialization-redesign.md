# 从博客到产品站：我的网站商业化重构记录

这个网站最初只是一块自留地——随手写点笔记、放几个实验项目。随着 docx-formatter-cn 逐渐成形，我意识到它不能再只是一个「博客」，而得承担起**产品主页**的职责：让访客一眼就知道我能提供什么、为什么值得付费、以及哪里能找到免费试用。

## 一、导航重构：三分结构

原来的导航是典型的博客菜单：

> 首页 / 服务 / 写作 / 笔记 / 归档 / 标签 / 项目 / 关于 / 联系

项太多、重点模糊。我把它压缩成三层：

- **产品**：在线工具、docx-formatter-cn、使用文档
- **服务**：论文排版服务、定价方案
- **自留区**：博客、笔记、关于

这样访客 3 秒内就能判断：「我是来找工具的」「我是来买服务的」还是「我只是来看看这个人写什么」。

## 二、首页：产品优先

旧首页是一块大 Hero 加最近文章。新版首页把**主打产品**放到视觉中心：

- 首屏直接介绍「在线 Markdown 转 Word」
- 给出「免费试用」和「查看定价」两个 CTA
- 下方保留自留区入口，但不再与产品抢注意力

这个改动让首页跳出率的意义发生了变化：不再只是「有没有人读我的文章」，而是「有没有人点击产品」。

## 三、CTA 链路打通

产品页、定价页、服务页之间的按钮之前各说各话。统一之后：

| 页面 | 主 CTA | 次 CTA |
|------|--------|--------|
| `/tools` | 免费试用 | 查看定价 |
| `/projects/docx-formatter-cn` | 在线试用 | 阅读文档 |
| `/pricing` | 选择方案 | 先试用免费版 |
| `/services/thesis-formatting` | 立即咨询 | 查看定价 |

每一页都给出下一步，不让用户在原地犹豫。

## 四、保留一块自留区

商业化不等于把个人内容全删掉。我在 `/blog`、`/notes`、`/about` 顶部加了一个「🌱 自留区」标识，明确告诉访客：

> 这里不是产品页，是个人创作空间，更新频率和风格都不受商业目标约束。

这个边界很重要。它让我在写推广文案的同时，还能保留写随笔、实验和碎碎念的Permission。

## 五、下一步

- 把 `/tools/md2docx` 的模板库继续扩充到更多高校与期刊
- 给产品页增加用户案例与截图
- 考虑接入支付，让 Pro 桌面版可以直接在站内购买

这次重构不算大，但它让网站从一个「作品集」变成了一个「小生意的起点」。
